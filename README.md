# Coca-Cola Zero visual benchmark

[Open the gallery](https://highsierraloft.github.io/coca-cola-zero-landing-pages/) to compare 18 independently generated landing pages.

Each model folder contains its static HTML, CSS, JavaScript, and assets. No build step is required.

## Prompt

> No skills are allowed. Create a beautiful landing page for Coca-Cola Zero using only plain AI. It can use custom design libraries. It must have at least five sections, with the hero section on top.

The gallery identifies each model and reasoning setting. Generated pages retain their original appearance, errors, and demo controls.

This is an unofficial design comparison, not affiliated with The Coca-Cola Company. Asset credits and font licenses remain alongside the relevant files.
